# ver0.1.7 — 2026/10/19

## 新機能

- **自律行動（ボイス／ステージ配信）**: 話したいゲージに応じてボットが通話へ入り、独り言とコメントへの応答を投稿・読み上げ。既定はOFFで、`/functions` → 💬 自発会話から設定。静音時間・無応答・時間上限で退出し、`/leave`で停止できる
- **自発会話パネル**: テキストの話題提供と自律行動の設定を集約し、ゲージ・配信先・退出条件を表示。配信コメントはメンション不要で、画像にも対応。個人の長期記憶は配信へ渡さない
- **開発者用ダッシュボード**（`tools/console/`）: SSH経由で概要・ライブログ・サービス操作・DBデータ・サーバー・接続を管理。DBは読み取り専用で、収集停止ユーザーの発言・解析を持ち帰らない。伏せ字、画面幅に応じた表示、キー操作にも対応
- **デプロイ**: 設定ブランチを早送りで更新し、必要な依存更新・再起動・ログイン成功の確認まで実行。失敗時はコードと依存関係を巻き戻す（DBは戻さない）
- **開発用起動**: `start-dev.ps1`で追加ターミナルを開かずに起動し、専用ブラウザを閉じると関連プロセスも終了。共有した依存フォルダからのフォント配信にも対応

## 運用・構成の整備

- **ソース・テストの再配置**: `index/`を`src/`へ変更し、`persona_bot/`を用途別に分割。回帰テストも分類し、音声テストと一覧を整理。`.env`・記憶・NGデータの保存先とペルソナの相対パスは維持
- **既存環境の更新**: systemdの`WorkingDirectory`を`<PROJECT_ROOT>/src`へ変更し、`sudo systemctl daemon-reload` → `sudo systemctl restart bot` → `systemctl status bot`で確認。手動起動は`cd src` → `python bot.py`
- **CI・検証環境**: ボットと管理コンソールのバックエンドをWindows／Linux・Python 3.10／3.13で検証。画面のテスト・ビルド、CodeQL、日本語グラフのフォント検証も整備
- **導入・保守資料**: SSH・sudoersの設定例、移行・日本語フォント・検証・プライバシー手順と構成図を更新。管理コンソールはホスト鍵を検証し、ローカル待受・操作コマンドの制限・本番環境の確認表示を実装
- **既定のモデル**: 既定とモデル選択肢のFlash LiteをGemini 3.1からGemini 3.5 Flash Liteへ変更。3.1を保存していたサーバーは次回起動で3.5へ移る（記憶ルーティング・モデレーションは3.1のまま）

## 不具合修正

- **タイムゾーン**: `tzdata`を依存に追加し、WindowsやOSのタイムゾーンDBがない環境で日本時間を使えず、予定・記念日・統計・自律行動の時間帯制限がUTC基準になる問題を修正
- **Gemini SDKの起動互換性**: 旧SDKに存在しない`enterprise`引数を渡さず、新旧共通の設定でDeveloper APIへ接続。HTTPXトランスポートも明示して、APIキーのヘッダー送信・再試行制御・終了時の回収を維持
- **検索付きの返信**: 選択モデルの検索が利用枠（429）で断られると返信がエラーで終わる問題を修正。検索用のGemini 2.5 Flashで検索し、それも断られたら検索なしで返信する（Gemini 3以降の検索は無料枠に含まれない）
- **起動手順**: Windows／Linuxとも仮想環境のPythonを直接指定し、通常のPythonにある別版SDKとの取り違えを防止
- **記憶・保存データ**: 圧縮・移行・同時保存でユーザーの記憶や文書要約が失われる問題を修正。JSONとDBの保存失敗時は復元・再試行し、壊れた旧データや取り込めない手書きプロフィールを保護
- **文書・画像**: 空の回答、添付要約の欠落、完了後の二重返信を修正。容量・形式を検証し、終了・例外・キャンセル時も画像・一時ファイル・遠隔アップロードを回収。中断した文書タスクは次回起動で復旧
- **会話・設定**: 応答開始時のペルソナ・モデル・検索設定を維持し、会話リセットの境界を修正。無効な保存設定は既定値へ戻し、BOM付きファイル、LLMのnull・不正なJSON、参考URLの欠落・重複に対応
- **自律配信・自動投稿**: 開始・停止・接続変更の競合と誤ったクールダウンを修正し、所有する接続・配信枠だけを回収。自発会話OFF時のお祝いを停止し、投稿権限・送信先・メンション通知を適切に制御
- **ボイス**: 接続・発言権限の事前確認とステージの発言者昇格を追加。内部タグ・記号だけの合成、音色の不正値、再生待機の中断・接続差し替え時の回収を修正
- **リマインダー**: 同時登録時の件数上限、本人だけへの通知、通知先の権限確認を修正。繰り返しを継続できない予定は停止として記録し、一覧・取り消しメニューと日時解釈を改善
- **統計・パネル**: 応答の期限切れ、長文・グラフの表示失敗、選択肢の欠落と権限変更後の操作を修正。不完全な解析は再試行し、収集停止・削除後の古い結果や表示名を残さない
- **利用制限・NGワード**: ブロック中のコマンド・パネル操作と活動観測を停止。違反記録の不正値に対応し、NGワードの再読込失敗時は従来の判定を保持
- **管理コンソール**: 確認時の接続先・接続時刻を照合し、デプロイ中の接続変更を拒否。古い応答・タイマー・キャッシュ・一時停止状態を整理し、伏せ字の漏れとサーバー間のエラー波及、旧DB・日本時間の日別集計を修正

## 内部修正

- **Gemini・PDF処理**: `google-genai`の共有クライアントへ移行してAPI呼出を非同期化。生成期限と検索非対応時の退避を統一し、PDF検証を`pypdf`へ集約。依存関係の版も固定
- **非同期処理・終了処理**: DB・ファイル・画像・音声の同期処理をワーカーへ移動。キャンセル時も処理の完了までロックを保持し、文書ワーカーの回収後にDiscord・Gemini・DBを終了
- **共通化・分離**: ペルソナ読込、グラフ保存・描画ロック、送信権限・長文・選択肢・パネル処理を共有化。メッセージ処理、自律行動の計算・ステージ管理、管理コンソールのDB集計・操作フックを分離し、定数と未使用コードを整理
- **DB更新**: スキーマをv10へ更新し、自律行動の設定列とリマインダー検索用索引を追加。移行をトランザクション化し、親密度・統計は対象ユーザーの行だけを保存
